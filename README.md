# Archetype for Mac

Downloads of the Archetype desktop app. This repository holds releases only;
there is no code here.

**Download:** [heyarchetype.com/app](https://www.heyarchetype.com/app), or the
`.dmg` under [Releases](../../releases/latest).

Archetype for Mac is an early build that Apple hasn't notarized yet, so macOS
asks you to confirm it the first time:

1. Open the `.dmg` and drag **Archetype** into **Applications**.
2. Open Archetype. When macOS says it can't check it, click **Done** (**OK**
   on some Macs), not **Move to Trash**.
3. Go to **System Settings → Privacy & Security**, scroll down and click
   **Open Anyway**.
4. Confirm with your password. From then on it opens like any other app.
